Dev Stack

Project Description
Dev Stack is a responsive web application that helps developers explore different technologies and build their ideal development stack. Users can browse technology cards and add or remove technologies from their personal stack.

Technologies Used
- React
- TypeScript
- Vite
- Tailwind CSS
- React Toastify
- Lucide React

Main Features
1.Technology Explorer:** Browse technologies with their descriptions, categories, difficulty levels, and ratings.
2. Personal Stack Builder:** Add technologies to a stack, remove individual items, or clear the entire stack.
3. Interactive Notifications:** Receive success, warning, and informational notifications when managing technologies.

React Questions and Answers

1. What is React?
React is a JavaScript library used to build interactive user interfaces with reusable components.
 2. What is a component in React?
A component is a reusable piece of UI that can contain its own structure, logic, and styling.

 3. What are props in React?
Props are inputs passed from a parent component to a child component.

4. What is state in React?
State is data managed by a component that can change over time and trigger a re-render.

 5. What is the useState hook?
The `useState` hook lets functional components store and update state.

6. What is the useEffect hook?
The `useEffect` hook lets components perform side effects, such as fetching data or synchronizing with external systems.

7. What is conditional rendering?
Conditional rendering means displaying different UI elements depending on a condition.
